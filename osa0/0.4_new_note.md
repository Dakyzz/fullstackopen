    participant browser
    participant server

    Note over browser: User writes a note and clicks "Save"
    
    browser->>server: POST /new_note (note content)
    activate server
    Note right of server: Server saves the new note to database
    server-->>browser: HTTP 302 Redirect to /notes
    deactivate server

    browser->>server: GET /notes
    activate server
    server-->>browser: HTML page with updated notes
    deactivate server

    browser->>server: GET /main.css
    server-->>browser: CSS file

    browser->>server: GET /main.js
    server-->>browser: JavaScript file

    browser->>server: GET /data.json
    server-->>browser: JSON list of all notes
    
    Note right of browser: Browser renders the updated note list
